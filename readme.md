# 🍇 Fruit of the Spirit - Word Search (CG Ice Breaker)

Aktivitas permainan *ice breaker* interaktif berbasis web statis (HTML/CSS) untuk kelompok sel (*Care Group* / *Cell Group*). Menggunakan konsep tebak situasi kehidupan sehari-hari ala Gen Z, kemudian mencari padanan kata 9 Buah Roh (*Fruit of the Spirit* - Galatia 5:22–23) dalam bahasa Inggris di papan huruf acak (*Word Search*).

---

## 🎯 Aturan & Format Permainan

- **Format Game**: Berbasis giliran (*turn-based*) antara 2 kelompok (Tim Hijau vs Tim Biru).
- **Media**: Dicetak pada 1 lembar kertas A4 (*Landscape*) menggunakan 2 spidol berbeda warna.
- **Tantangan**: Leader membacakan *clue* situasi tanpa menyebutkan kata kuncinya. Tim harus menerjemahkan tindakan ke dalam kata Buah Roh bahasa Inggris, lalu menemukannya di papan kata.
- **Batas Waktu**: 30 detik per giliran (disarankan memakai timer bersuara lucu/bom di HP).
- **Kondisi Menang**: Tim pertama yang berhasil mengumpulkan dan menandai **5 poin** keluar sebagai pemenang.
